# .github

**ExTrakf is an organization with many lolicons.**

This repository hosts the public [organization profile](profile/README.md) — the page shown on [github.com/ExTrakf](https://github.com/ExTrakf) — plus default community health files.

## Layout

| Path | Purpose |
|---|---|
| [`profile/README.md`](profile/README.md) | Organization profile page (shown on the org overview) |
| [`src/images/`](src/images/) | Image assets used by the profile page |

## Preview locally

GitHub only renders `profile/README.md` on the organization page; push to `main` and visit <https://github.com/ExTrakf> to see it live.
